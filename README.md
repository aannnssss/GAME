# Тема: 3D игра от первого лица, в которой игрок исследует огражденный город, собирает ресурсы и избегает столкновений с зараженными людьми и токсичным облаком. Собрав все ресурсы, игрок подрывает туннель и освобождается  
# Механики:
- сбор ресурсов (взрывчатка, спички, лом);  
- зараженные люди (nav mesh) передвигаются по определенному маршруту и, если игрок попадает в определнный радиус, то идут к нему. Создан слой защиты (можно присесть и спрятаться за баками и машинами). Если зомби догоняет - конец игры;  
- токсичное облако (particle system) двигается по маршруту, и если попасть в него - конец игры;  
- мигающие фонари;  
- подрыв туннеля и разлет камней.

# Управление
- WASD: перемещение игрока  
- Мышь: управление камерой  
- E: взрыв туннеля  
- ctrl: присед  
- shift: бег  

# Скрипты
- ```CloudMovement```: Управление движением токсичного облака по точкам патруля с плавным парением;  
- ```CollectItems```: Обработка подбора ресурсов (проверка тега, обновление счётчиков, исчезновение объекта);
- ```FinishLineTrigger```: Активация зоны победы после взрыва туннеля;
- ```FlickerLight```: Случайное мерцание источника света для атмосферы;
- ```GameManager```: Центральный менеджер игры (хранение прогресса ресурсов, проверка условия побега);
- ```IntroUI```: Отображение стартового экрана, обработка кнопки "ок";
- ```MouseLook```: Cчитывает движение мыши, разделяет его на две оси: вертикальную (для наклона камеры с ограничением угла) и горизонтальную (для разворота всего персонажа), блокирует курсор для погружения в игру;
- ```PlayerMovement```: Физика движения игрока: ходьба, бег, приседание с изменением коллайдера и позиции камеры;
- ```ToxicCloud```: Логика токсичного облака: патрулирование, визуальное парение, триггер проигрыша при контакте;
- ```TunnelExit```: Обработка финального взаимодействия (проверка ресурсов, запуск последовательности взрыва, физика обломков);
- ```ZombieAI```: ИИ заражённых (патрулирование, обнаружение игрока через луч, преследование, проигрыш при поимке).
